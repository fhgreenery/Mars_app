# Mars Sport (火星运动)

Mars Sport is an Android pedometer and social fitness app built around the idea of "happy exercise". Busy people often only have short, scattered moments to be active. The app counts those steps, draws the route you walked or ran, and lets you share the result with friends, all in a light, blue-themed interface meant to feel relaxing rather than competitive.

> 快节奏生活下人们只能利用碎片时间来锻炼。“火星运动”是一款以“快乐运动”为主题、集运动与减压为一体的计步软件，具体功能有：计步、轨迹绘制、好友留言、运动圈发表、天气预报、音乐播放。

## Features

- **Step counting.** Uses the hardware step counter and step detector sensors when the phone has them, with an accelerometer-based fallback. Shows steps, distance, average speed and calories burned, against a daily goal you set from your height, weight, stride length and age. Detection sensitivity can be tuned.
- **Step history and ranking.** Daily records are synced to the cloud, shown as charts, and ranked against other users.
- **Route tracking.** Draws your route live on a Baidu map using GPS and the orientation sensor, filters out location drift, and can save a screenshot of the finished track.
- **Moments (运动圈).** Post text and photos about a workout, browse a feed with comments, and view images full screen.
- **Messages.** Leave messages for friends, including voice messages, and find nearby users on the map.
- **Push notifications.** Receive announcements and push messages, with an in-app message list.
- **Weather.** Current conditions and a multi-day forecast for your location.
- **Music.** A built-in local music player that keeps playing in the background with a notification control.
- **Account and settings.** Register, log in, reset your password, edit your profile, tune motion and light sensitivity, and send feedback.

## Tech stack

| Area | Technology |
| --- | --- |
| Language | Java 8 (lambdas via Retrolambda) |
| Platform | Android SDK 25 (min SDK 19), Android Support Library 25 (Design, CardView), MultiDex |
| Build | Gradle 3.3, Android Gradle Plugin 2.3.1 |
| Backend (BaaS) | [Bmob](https://www.bmob.cn/): cloud data storage, file storage, user accounts, push (`bmob-push`), instant messaging (`bmob-im`), SMS verification (`bmob-sms`), in-app update |
| Maps and location | Baidu Map SDK and Baidu Location SDK (`BaiduLBS_Android.jar` and native `.so` libraries) |
| Weather | Baidu weather API over HTTP |
| Local database | greenDAO 3 (SQLite ORM, entities and DAOs generated by `MyDaoGenerator`) |
| Networking | OkHttpFinal, OkHttp 3, Gson |
| Images | Glide 3, TakePhoto (camera and gallery picker), NineGridImageView, Banner, EasyBlur |
| UI | BaseRecyclerViewAdapterHelper, EasyRecyclerView, Lottie, FloatingActionButton (Clans), SuperTextView, SwipeCardsView, NineOldAndroids, plus custom views (charts, progress wheel, arc menu, falling-snow animation) |
| Sensors | Step counter, step detector, accelerometer, orientation and light sensors |
| Voice | Recording library (`RecordVoiceButton`) for voice messages |
| Architecture helpers | ButterKnife (view binding), EventBus, AndPermission (runtime permissions), HelloDaemon (keep-alive background service) |
| Debugging | Stetho, LeakCanary, a custom crash handler, Log4j |


## Getting started

1. Open the project in Android Studio. It targets an older toolchain (Gradle 3.3, Android Gradle Plugin 2.3.1, build tools 25.0.2), so an older Android Studio or JDK 8 works best.
2. In `app/build.gradle`, point `signingConfigs.config` at your own keystore, or remove it to build with the default debug key.
3. Replace the Bmob application ID in `App.java` and the Baidu Map API key in `AndroidManifest.xml` with your own keys.
4. Build and run on a device. A phone with a step counter sensor gives the most accurate step counts.

A prebuilt APK is also included at `app/app-release.apk`.
